# 顶部模板标签

2026-09-05：按用户截图，将品牌模板从右侧移至中栏品牌简报上方，显示为紧凑、可换行的标签，点击直接套用。保存及删除入口放入默认折叠的「管理模板」，预设模板禁止删除。

设计依据：上级 spec/design/pc-design.md 与 spec/design.md。历史页面色值与共享规范存在差异；此次新增模板区域使用共享色彩 Token，保留用户指定的三栏位置及紧凑标签。桌面标签至少 32px 点击高度，移动端至少 44px，支持中文换行、键盘焦点、加载、空数据及请求失败重试。

验收：1440、1104、768、375px 下模板位于表单上方、右侧仅保留模型配置、关键卡片不归零；套用填充正确，管理展开可保存及删除，预设删除禁用。后端 API 不变。
